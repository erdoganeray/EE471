# EE471 - Modern Software Development Practices and Technologies

Izmir Institute of Technology, Electrical and Electronics Engineering Department.

## About the Course

This course covers modern software engineering practices and technologies, including version control systems, object-oriented programming, clean coding, cloud/AI services, containerization, front-end/back-end and mobile development fundamentals, CI/CD, and agentic AI, covered on a weekly basis.

- **Instructor:** Cihan Göksu, PhD.
- **Credits:** 3 hours/week, 15 weeks

## conform.py

Solution to the Week 0 puzzle: minimizing the number of commands needed to make everyone in a line flip their cap (Forward/Backward) to the same orientation. Includes a variant that skips bareheaded (H) positions.

Run with:

```
python Week1/conform.py
```

## Requirements

- Python 3.10+
